# 蒋财报 · 支持页与隐私政策

Support page and privacy policy for 蒋财报, an iOS app that explains financial reports from 11 markets in plain language. Live at https://wordscontrols.github.io/jiangcaibao/

这个仓库只放两个静态页面，由 GitHub Pages 托管：

- 支持页：https://wordscontrols.github.io/jiangcaibao/ （`index.html`）
- 隐私政策：https://wordscontrols.github.io/jiangcaibao/privacy/ （`privacy/index.html`）

App 本身在 App Store：https://apps.apple.com/app/id6803445711 。App 的代码不在这个仓库里。

## 改动前请看

这两个地址是给 App Store 用的支持网址和隐私政策网址。**不要改仓库名，不要移动 `privacy/` 目录**，否则外部指向它们的链接会全部失效。

改文案直接编辑对应的 HTML 文件，推到 `main` 后 Pages 自动更新。

反馈请用支持页上的邮箱。
